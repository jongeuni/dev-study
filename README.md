# dev-study

개발 공부 기록 저장소입니다. 기존에 나뉘어 있던 4개 저장소(`languageStudy`, `study`, `springboot`, `book`)를
카테고리 기준으로 통합했습니다. (각 폴더는 원본 저장소의 커밋 히스토리를 그대로 보존합니다.)

## 폴더 구조

- [`Language/`](./Language) — 언어별 학습 정리 (C++, JAVA, JS, Kotlin, Python)
- [`CS/`](./CS) — REST API, IT Infra, Git, 자료구조 등 CS/개발 일반 개념 정리
- [`SpringBoot/`](./SpringBoot) — Spring Boot 코드 예제, 디자인 패턴, JPA, REST Docs 정리
- [`Books/`](./Books) — 개발 관련 도서 독서 노트 (Clean Code, DDD Start! 등)

## 원본 저장소

- languageStudy → `Language/`
- study → `CS/`
- springboot → `SpringBoot/`
